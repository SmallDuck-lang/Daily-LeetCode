### 46. 全排列（中等）
- **力扣链接**：[46. 全排列](https://leetcode.cn/problems/permutations/)
- **保存为**：`problems/permutations.js`
- **思路**：利用回溯思想枚举所有排列：维护一个正在构建的路径数组path和标记数组used记录数字是否已选用，循环遍历所有数字，跳过已选数字(used[i]为true)，先选中当前数字并标记，递归继续填充下一位，当路径长度等于原数组长度时拷贝路径存入结果集，递归返回后撤销本次选择、清除标记，继续尝试其他候选数字，直到枚举完全部可能性。
- **卡点**：存答案必须拷贝数组：res.push([...path])，不能直接 push path。path 是引用对象，后续 pop 会修改原数组，最终结果全部出错。
- **一句话总结**：回溯核心就是选元素、递归、回溯撤销；用 used 标记避免同一条路径重复选取元素，收集答案时复制路径快照，递归返回一定要撤销选择，保证不影响后续分支搜索。

### 78. 子集（中等）
- **力扣链接**：[78. 子集](https://leetcode.cn/problems/subsets/)
- **保存为**：`problems/subsets.js`
- **思路**：用回溯生成子集，start参数控制遍历起点，保证只向后选元素避免重复子集；每次进入递归先把当前路径拷贝存入结果（每一个 path 都是合法子集），循环中选择当前元素，递归从下一个位置继续搜索，递归返回后撤销选择，枚举所有选或不选的组合。
- **卡点**：子集不是等到长度够了才存，只要进入回溯函数，当前 path 就是一个子集，立刻保存；所以一开始空数组[]就会被收进去。
- **一句话总结**：和全排列最大区别：  
全排列：i 从 0 开始循环，需要 used 数组，要等 path 填满才收集答案  
子集：i 从 start 开始，不需要 used，只要进来就收集 path，天然不会重复
