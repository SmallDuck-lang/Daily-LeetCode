# problems/

这个目录用来存放你的 LeetCode 题解代码。

## 自动同步

如果你安装了 **LeetHub** 插件，AC 之后代码会自动 push 到这里，目录结构由插件决定，通常是：

```text
problems/
├── easy/
├── medium/
└── hard/
```

## 手动存放

如果没有插件，建议按以下方式手动保存：

```text
problems/
├── 0001-two-sum.js
├── 0049-group-anagrams.js
└── 0206-reverse-linked-list.js
```

每 AC 一题后顺手 commit：

```bash
git add problems/0001-two-sum.js
git commit -m "feat: 1. 两数之和 (哈希)"
git push
```

---

> 面试官点开你的 GitHub，看到这个目录里密密麻麻的提交记录，本身就是最好的执行力证明。
